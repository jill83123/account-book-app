# 記帳本

離線優先的記帳 PWA。

資料先存在裝置上，可選擇同步到你自己的 Google 試算表，並能安裝到手機桌面。

> 本專案僅供個人使用。

**技術**：Vite、Vue 3、Tailwind CSS、Pinia、Dexie（IndexedDB）、vite-plugin-pwa。

## 功能

### 記帳

- **一筆記錄多個品項**：去好市多買了杏鮑菇、蘋果汁、洋芋片，可在同一筆記錄裡用上方的品項分頁，分別記成食材、飲料、零食，合計自動加總。多品項的記錄以**多類別**圖示表示，不以第一個品項為主。
- **細項**：品項下可再分細項（例如早餐的漢堡加紅茶），只記名稱和金額，不用選分類。用過的細項會變成快速新增的按鈕，品項金額是細項的加總。
- **同行的人**：可選**和誰一起**，名字用輸入的，之後會記住常用的；查看記錄與搜尋都看得到。
- **時間與當天順序**：時間可以不填。首頁每一天長按一筆再上下拖，就能調整當天的順序。

### 查看與編輯

- **查看與複製**：點一筆記錄會先開查看視窗（品項、帳戶、商家、備註、附加圖片），可從裡面編輯、複製成新的一筆或刪除。品項可長按拖曳調整順序。
- **批次編輯**：按首頁右上角的批次編輯鍵（搜尋結果頁是**選取**），勾選後可一次改分類、商家、帳本或刪除，改完可按**復原**。

### 首頁

- **三個視圖**：
  - **帳單**（預設）：整個月依日分組的列表，每筆標出分類與商家。
  - **月曆**：整月收支加月曆，每天底下標收入與支出，點一天就在月曆下方列出那天的明細。
  - **月報**：一年十二個月的收入、支出與結餘。
- **切換帳本**：點一下標題。

### 分類、商家與預算

- **分類管理**：大分類一列一個，點進去看子分類，每個都有自己的圖示與顏色（圖示分成十二類，共兩百多個）。可編輯、隱藏（舊記錄照樣保留）、長按拖曳排序；刪除在編輯畫面裡，已有記錄的不能刪。
- **商家與品項記憶**：品項名稱旁的星號決定要不要記住這個品項，只有加星號的品項會記在商家底下。選了商家後，輸入品項時下方會出現加星號的品名（依次數與最近使用排序），點一下就帶入名稱、分類與上次價格。沒選商家時，打字會從所有商家的品項裡找。
- **每月不同的預算**：分類和帳本各有一個預設的每月預算。到**統計 → 預算**，點分類或**調整這個月**，可以只改某個月，其他月份照預設。

### 帳戶、帳本與進階功能

| 功能               | 說明                                                                                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 帳戶與資產         | 現金、銀行、電子錢包、信用卡。信用卡顯示上期帳單與本期累計，轉帳可用來還款。                                                                                                                                 |
| 帳本               | 把記帳分成日常、旅行等獨立的本子，各自有每月預算。                                                                                                                                                     |
| 週期交易           | 房租、訂閱、薪資。可選自動入帳，或到期出現在提醒由你確認。                                                                                                                                                   |
| 分期               | 把一筆大額消費拆成每月一期自動入帳，可加每期手續費，並追蹤剩餘金額。                                                                                                                                         |
| 攤提               | 一筆支出分成 N 個月計入報表（例如年繳保險），現金仍在付款當天扣除。在**更多 → 攤提**裡挑一筆支出設定月數；統計與試算表月報可切換是否攤提。                                                                     |
| 外幣帳本           | 一個帳本就是一種幣別（例如日本旅行用 JPY），記錄直接用該幣別輸入，不用逐筆填匯率。旅行結束後，在首頁的提示輸入實際花掉的新台幣總額，系統會依比例換算每一筆並記下匯率。                                   |
| 分帳、代墊、別人付 | 一筆支出可選平均分、自訂或代墊。統計與首頁合計只算你自己的部分，帳戶仍扣掉實際付出的全額；其他人的份額會自動變成借款，並保留回原記錄的連結。選別人付時不會扣帳戶，並自動記一筆你欠對方的借款。 |
| 借款               | 分成別人欠我、我欠別人、已結清三區，各區有合計。點進去可部分還款（金額欄留空，或按全額一鍵填入）、看到是哪一筆分帳產生的，並可選擇影響哪個帳戶的餘額。資產頁會顯示應收與應付。                   |

### 提醒、統計與 AI

- **提醒**：每日記帳提醒、待確認的週期交易、信用卡繳款日、借款到期日。處理完或手動封存的提醒會留在已結束提醒區 30 天，之後自動清掉。
- **統計**：圓環圖與分類明細、預算進度、依品項彙整，可按月、按年或自訂日期範圍。
- **AI 發票辨識**：拍照交給 Gemini（免費額度），自動讀出商家、日期與品項，並依你的分類歸類。也可以複製提詞到任何 AI 對話，再把回覆貼回來。

## 快速開始

需要 Node.js 22.18 以上（或 24.12 以上）。

```bash
npm install
npm run dev          # http://localhost:5173（區域網路內的手機也能開）
```

| 指令              | 用途                           |
| ----------------- | ------------------------------ |
| `npm run dev`     | 開發伺服器                     |
| `npm test`        | 執行單元測試（Vitest）         |
| `npm run build`   | 型別檢查並建置到 `dist/`       |
| `npm run preview` | 預覽建置結果                   |
| `npm run lint`    | oxlint 與 ESLint（會自動修正） |
| `npm run format`  | 用 Prettier 格式化 `src/`      |

不設定任何雲端服務也能完整使用，資料只存在這台裝置，可用**更多 → 備份與資料**匯出 JSON 備份。同步與推播是選配。

## 部署前端（GitHub Pages）

推送到 `main`，`.github/workflows/deploy.yml` 會先跑測試、再建置並部署。第一次要在 repo 的 Settings → Pages 把 Source 設為 **GitHub Actions**。只改 `worker/` 的推送不會觸發前端部署。

## Google 試算表同步

選配。以下設定只需做一次，App 的**更多 → Google 試算表同步**裡也有同樣說明。

1. 在 Google Cloud Console 建一個專案（名稱自訂，個人專案即可），啟用 **Google Sheets API** 與 **Google Drive API**。
2. 設定 OAuth 同意畫面（外部），把你自己加入測試使用者。長期使用建議把發布狀態改成**正式版**：維持**測試**狀態的話，授權每 7 天會過期要重新登入。個人使用不需要送審，登入時會看到未驗證的提醒，按**進階**繼續即可。
3. 建立 OAuth 用戶端 ID（網頁應用程式），已授權的 JavaScript 來源欄位填 GitHub Pages 網址（開發時再加 `http://localhost:5173`）。
4. 部署 `worker/`（用來換發長效授權，步驟見下方〈部署 Worker〉）。
5. 在 App 貼上 Worker 網址，登入 Google。

App 只要求 `drive.file` 權限，只能看到自己建立的那份試算表，碰不到雲端硬碟裡的其他檔案。

### 部署 Worker

在你自己的 Cloudflare 帳號下，於 `worker/` 內操作。設定都寫在 `wrangler.local.toml`：它已被 git 忽略，第一次會從 `wrangler.toml` 自動複製出來，私鑰不會進到 git。

```bash
cd worker
npm install
```

1. 產生推播金鑰。公鑰與私鑰會直接寫進 `wrangler.local.toml`，不會印在畫面上：

   ```bash
   node scripts/gen-vapid.mjs
   ```

2. 填好 `wrangler.local.toml` 的其他欄位：

   | 欄位               | 說明                                                                                      |
   | ------------------ | ----------------------------------------------------------------------------------------- |
   | `GOOGLE_CLIENT_ID` | 上面建立的 OAuth 用戶端 ID（不是機密）                                                    |
   | `ALLOWED_ORIGINS`  | 允許呼叫 Worker 的來源，以逗號分隔（GitHub Pages 網址，開發時加 `http://localhost:5173`） |
   | `VAPID_SUBJECT`    | 推播服務有狀況時的聯絡方式，格式為 `mailto:你的信箱` 或網站網址，不可留空；不會真的寄信   |

3. 設定 Google 用戶端密鑰：

   ```bash
   npx wrangler secret put GOOGLE_CLIENT_SECRET
   ```

4. 部署。有欄位沒填會停下來並列出；部署時會把推播私鑰改存成 Cloudflare 的加密密鑰：

   ```bash
   npm run deploy
   ```

> `npm run deploy` 會檢查推播金鑰都已填好，所以即使只想用試算表同步，也要先完成步驟 1、2。

## 推播提醒

選配，讓 App 關閉時也能收到提醒。App 會把這台裝置的推播訂閱，加上未來 14 天的每日提醒內容上傳；Worker 為每台裝置設一個 Durable Object 鬧鐘，到時間就準時發送，不用定期輪詢。Worker 只存訂閱和簡短的提醒文字（例如：今天還沒有記帳），不存金額、對象、分類或任何帳目內容。

會提醒的事：

- 每日記帳（今天已經記過就不發）
- 信用卡繳款日
- 借款到期與逾期
- 週期交易待確認

提醒時間共用更多頁的每日記帳提醒設定，每天最多一則，同一天的事合併成一則。

**啟用**：先完成上方〈部署 Worker〉，再到 App 的**更多 → 每日記帳提醒**（在更多頁展開）打開**背景推播**，允許通知，按**傳一則測試通知**來確認。

**注意**：

- 重新產生金鑰會讓已開啟推播的裝置全部失效，需各自關閉再重新開啟，所以腳本預設不會覆蓋已有的私鑰（要覆蓋須加 `--force`）。
- iPhone 需要先**加入主畫面**，從主畫面開啟 App 才能授權推播。

## Gemini 發票辨識

有兩種方式，擇一即可：

- **直接呼叫**：到 [Google AI Studio](https://aistudio.google.com/apikey) 建立免費金鑰，貼到**更多 → AI 發票辨識**。金鑰只存在這台裝置，不會寫進試算表。
- **經由 Worker**：在 Worker 設定 `GEMINI_API_KEY` 密鑰（`npx wrangler secret put GEMINI_API_KEY`），金鑰就不會放在瀏覽器裡。App 已登入 Google 且設定了 Worker 網址時，會優先走這條路。

模型名稱可以在該頁用**列出可用模型**按鈕挑選。

## 試算表長什麼樣子

App 第一次同步時，會在你的雲端硬碟建立記帳本資料夾，並在裡面放一份記帳本試算表，自動整理成下列分頁（每次同步都會重新產生）：

資料夾與試算表建立後，你可以隨意搬到雲端硬碟的其他位置或改名，App 靠檔案 ID 找它們，不會再把檔案搬回去。

| 分頁            | 內容                                                                            |
| --------------- | ------------------------------------------------------------------------------- |
| 說明            | 各分頁用途                                                                      |
| 明細            | 每個品項一列，同一筆記錄的品項相鄰並共用底色，附記錄 ID；可直接篩選、做樞紐分析 |
| 月報            | 每個帳本每月的收入、支出、結餘，與各大分類支出                                  |
| 攤提            | 攤提支出每月分到的金額                                                          |
| 帳戶            | 各帳戶餘額、信用卡帳單、資產與負債合計                                          |
| 借款            | 借出借入、已還與未還、逾期狀態                                                  |
| 週期與分期      | 排程、下次日期、進度                                                            |
| 商家品項        | 每個商家記住的品項與常用價格                                                    |
| 分類            | 分類架構與預算                                                                  |
| 帳本            | 各帳本統計                                                                      |
| `_data`（隱藏） | App 同步用的原始資料，請勿修改或刪除                                            |

試算表上的分頁是產生出來的檢視，要修改請回 App 做；想自己分析，請複製分頁，或另開分頁引用明細分頁。多台裝置之間以每筆資料的更新時間為準，較新的覆蓋較舊的。

## 已知限制

- 背景推播需要先部署 Worker。沒有開啟時，每日提醒只會在你打開或切回 App 時出現。
- 帳本的幣別建立後，裡面有記錄就不能再改。台幣金額以整數計算，外幣的原價可以有小數。
- 掃描發票用的照片只用於辨識，不會被儲存。用附加圖片功能放入的照片會縮小後存在這台裝置上（約幾十到幾百 KB），不會同步到 Google 試算表，也不在 JSON 備份裡。
